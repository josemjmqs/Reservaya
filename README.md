# Reservaya

Plataforma de reservas online para pequeños negocios (talleres, peluquerías,
consultas, etc.). Cada negocio tiene su página pública donde sus clientes
pueden reservar una hora sin necesidad de crear una cuenta.

## Problema que resuelve
Muchos negocios agendan por WhatsApp o llamadas, lo que genera cruces de
horarios y pérdida de tiempo. Este proyecto automatiza ese proceso.

## Stack
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Node.js, NestJS, TypeScript
- Base de datos: PostgreSQL + Prisma
- Infraestructura: Docker, GitHub Actions

## MVP
**Negocio:** registro, configuración de servicios y horarios, agenda, bloqueos.
**Cliente:** ver horas disponibles, reservar, cancelar por enlace de correo.

## Fuera del alcance (por ahora)
Pagos, WhatsApp, múltiples sucursales, campos personalizados.
